# 调研：AI 视频制作 SOP（2026-08）

> 来源：庞果设计、阿里云 ModelScope、腾讯云/百度开发者、Colossyan、ElevenLabs、视频生产开源 skill 等。

## 进阶调研（GitHub 开源项目，2026-08 补充）

升级方案 B 与新增方案 D 的依据：

- **OpenMontage**（15.4k★）：世界首个开源 Agent 化视频生产系统，12 条 pipeline / 52 工具 / 500+ Agent skill；三层 Agent 架构（工具层→技能层→编排层）；预合成验证 + ffprobe 自审 + 供应商评分；预算治理（成本预估/支出上限/审批阈值）。成本参考：60s 动画 $1.33、60s 广告 $0.69。
- **movie-gen**（dawndrain/movie-gen）：5-12 分钟短片 ~$200/2.5h；核心方法论 **animatic-first**（静图+TTS 先预演再烧钱生成）；Anchors 角色锚点 + 首帧；音频先行；Director notes 最小修复（dub_clip 只换一句音轨）；Gemini 听音频 QA + F0 音调筛查。
- **ViMax**（港大）：导演/编剧/制片人/质检多 Agent；**三层递归规划**（事件→场景→镜头）；跨镜头一致性用 VLM 评分；多机位模拟。
- **speechlab0210/video-production-skill**：每句 Whisper ASR 回验相似度 ≥0.85 才放行；词级时间戳字幕对齐。
- **角色一致性三层策略**：①参考图定妆（--cref，70-80%）②ComfyUI InstantID+IP-Adapter→OpenPose→FaceDetailer（95%）③LoRA 训练（20-30 张，1500-3000 步）。
- **QC 工程化**：CLIP 文图一致性门禁、确定性机器可检规则、ffprobe 自审、断点续跑。
- **对口型音频预处理**：16-24kHz 单声道、去头静音、尾加 0.2s、-3dB；唱歌场景先 Demucs 分离人声。
- Prompt 优先级：**构图 → 主角 → 镜头运动 → 整体氛围**；CHARACTER DNA + 场景块模板。

## 核心共识

- 所有主流方案收敛到同一链路：**文 → 图 → 视 → 音 → 剪**
- 定题定位 → 脚本/文案 → 分镜 → 画面生成 → 配音配乐 → 剪辑合成 → 发布运营
- 70% 标准化流程 + 20% 人工审美 + 10% 技术调试；重剧本轻画面是最大坑，前 3-5 秒钩子决定成败

## 三种 SOP（本站已收录到 `src/data/sop/`）

| 方案 | 核心 | 时长/条 | 难度 |
| --- | --- | --- | --- |
| A 口播/讲解 | 大模型写稿 → TTS 配音 → 素材拼配/AI 配图 → 剪映合成 | 15-40 分钟 | 入门 |
| B 文生视频分镜剧 | 剧本 → 分镜表 → 角色一致性资产 → 分镜生成 → 配音配乐 → QA | 1-3 小时 | 进阶 |
| C 数字人口播 | 选工具 → 准备形象 → 口播文案 → 一键生成 → 后期 | ~20 分钟 | 入门 |

## 避坑要点

- 角色一致性靠「角色卡 + 多视角参考图 + 首尾帧」，否则崩脸
- 配音前先修口播文案标点（长句拆短、多逗号），TTS/口型同步全靠标点
- 配乐音量压到人声 ~30%；转场 200-300ms；AI 片每镜头 3-6 秒
- 免费工具会加水印/限 720p，商用先确认授权

## 2025-2026 主流工具一句话定位

- 生成式：Sora 2（电影级长镜头）、Veo 3.1（原生 4K + 音画同步）、可灵 3.0（中文剧情/物理真实）、即梦 Seedance 2.0（一站式零基础上手）、Vidu（多实体一致性）、Runway Gen-4.5（专业导演模式）
- 剪辑式：剪映/CapCut（新手必装全流程终端）、达芬奇/PR（专业精修）、Descript（文字时间线剪辑）
- 数字人：HeyGen（效果最好）、D-ID（性价比）、腾讯智影（国内免费友好）
- 配音/音乐：ElevenLabs（TTS 天花板）、MiniMax（中文音色强）、豆包/剪映（免费）、Suno（BGM）
