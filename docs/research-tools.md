# 调研：AI 工具汇总站（2026-08）

> 来源：There's An AI For That / Futurepedia / TopAI.tools / Toolify / AIxploria / a16z Top 100 等对比研究。

## 信息架构共性

- 双入口：按类别浏览 + 搜索/场景描述查找
- 多维度筛选：类别 + 价格 + 平台 + 标签 + 评分 + 上线时间，两步内完成
- 「最新收录 / New」是留存利器；趋势榜 + 编辑精选并存
- 2025-2026 趋势：AI Agent / 自动化工作流 / MCP 成为独立大类

## 展示形式要点

1. 卡片式信息密度：Logo + 名称 + 一句话描述 + 分类/价格标签
2. 卡片 Grid：`repeat(auto-fill, minmax(240px, 1fr))`
3. 移动优先（60%+ 流量来自手机）
4. 暗色模式（CSS 变量）
5. 数据与展示分离：工具条目放 JSON，改 JSON 即更新

## 分类框架（本站采用）

12 大类：对话助手 / 视频生成 / 图片生成 / 音频音乐配音 / 编程 / 写作 / 搜索引擎 / 办公效率 / 数字人 / 设计 / 学习教育 / Agent 自动化。
